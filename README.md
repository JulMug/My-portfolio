# Julien Busiho — Personal Portfolio

A personal portfolio showcasing my journey, skills, projects, and professional interests in **Frontend Development, Data Analytics, and Digital Innovation**.

## About

I am Julien Busiho, an aspiring Frontend Developer and Data Analyst based in Goma, Democratic Republic of the Congo.

I am passionate about building useful digital solutions through technology, data, and innovation. My interests include frontend development, data analytics, financial technology, and digital solutions with social impact.

## Objectives

This portfolio aims to:

- Present my professional profile and learning journey.
- Showcase my technical skills and projects.
- Share my experience in technology, finance, and innovation.
- Make it easier for recruiters, collaborators, and organizations to connect with me.

## Technologies

The project is built with:

- React
- Vite
- JavaScript
- Tailwind CSS
- DaisyUI
- Git and GitHub

## Portfolio Sections

The website will include:

- **Home:** Introduction and professional positioning.
- **About:** Background, interests, and motivation.
- **Skills:** Technical and professional competencies.
- **Projects:** Selected development and innovation projects.
- **Journey:** Education, training, and professional experience.
- **Contact:** Ways to get in touch.

## Getting Started

To run the project locally:

```bash
git clone https://github.com/JulMug/My-portfolio.git
cd portfolio
npm install
npm run dev
```
